# ✟ Святой Брейнфак — Holy Brainfuck (HBF)

**Святой Брейнфак** — эзотерический язык программирования по образцу Brainfuck,
в котором нет ни одного языческого знака: все команды — православные кресты
и священные символы. Их **16 — вдвое больше, чем восемь** в оригинальном Brainfuck.

Brainfuck произносит `> < + - . , [ ]` — Святой Брейнфак произносит
`♠ ♣ ♥ ♦ ☦ ✞ ✟ ✠ ✝ ☚ ☛ ✖ ☨ ☧ ☥ Ω`.

## Таблица команд

### Первая восьмёрка — как в Brainfuck

| Символ | Название | Действие | Аналог в Brainfuck |
|:------:|---|---|:------------------:|
| `♠` | Десница | указатель вправо | `>` |
| `♣` | Шуйца | указатель влево | `<` |
| `♥` | Благодать | прибавить 1 к ячейке | `+` |
| `♦` | Смирение | вычесть 1 из ячейки | `-` |
| `☦` | Возвестие | вывести ячейку как символ | `.` |
| `✞` | Откровение | прочитать один символ с ввода | `,` |
| `✟` | Молитва | начало цикла: прыгнуть за `✠`, если ячейка = 0 | `[` |
| `✠` | Аминь | конец цикла: вернуться на `✟`, если ячейка ≠ 0 | `]` |

### Вторая восьмёрка — сверх Brainfuck

| Символ | Название | Действие |
|:------:|---|---|
| `✝` | Крест | очистить ячейку: `c = 0` |
| `☚` | Шуйца-указ | приобщить к левому соседу: `tape[ptr−1] += c` |
| `☛` | Десница-указ | приобщить к правому соседу: `tape[ptr+1] += c` |
| `✖` | Андреевский крест | умножить на правого соседа: `c = c × tape[ptr+1] (mod 256)` |
| `☨` | Крест Лотарингии | обменять `c` с правым соседом |
| `☧` | Хриограмма | удвоить: `c = 2c (mod 256)` |
| `☥` | Крест с рукоятью | вывести ячейку как десятичное число |
| `Ω` | Омега | немедленно остановить программу |

## Устройство языка

- **Память** — кольцо из 30 000 ячеек по 8 бит; переполнение свёртывается по модулю 256.
- **Указатель** — в начале стоит на ячейке 0 и движется по кольцу вслед за `♠` и `♣`.
- **Ввод/вывод** — побайтовый; когда ввод кончился, `✞` кладёт в ячейку 0.
- **Останов** — `Ω` прерывает программу сразу, даже внутри цикла.
- **Мирская суета** — любой символ, не входящий в таблицы, не выполняется: буквы,
  пробелы, цифры, знаки препинания и «языческие» `>+-.,[]` обычного Brainfuck.
  Поэтому программу можно снабжать комментариями-молитвами на любом языке —
  лишь бы в них не встречались шестнадцать священных знаков.

## Полезные идиомы

- **Переселение вправо** (значение уходит вправо, ячейка обнуляется): `☛ ✝`
- **Переселение влево**: `☚ ✝`
- **Копия вправо** (если правая ячейка пуста): `☛`
- **Ноль**: `✝` — вместо цикла из `♦`
- **Удвоение**: `☧`; **умножение**: `✖` — вторым множителем служит правый сосед
- **Печать числа**: `☥` — вместо цикла из `♦` и `☦`
- **Стоп**: `Ω` — не нужно дожидаться завершения цикла

## Примеры

### 1. «Hello World» — `examples/hello.hbf`

Классическая программа Brainfuck, переписанная священными знаками и окружённая
молитвенными комментариями:

```text
Господи, помилуй! Программа «Hello World» на Святом Брейнфаке.
♠♥♥...   (тело программы из священных знаков)
Аминь.
```

### 2. Следующая буква — `examples/next_char.hbf`

Самая короткая осмысленная программа: прочитать символ, прибавить единицу,
вывести.

```text
Святая программа: назвать полученную букву следующей.
✞ ♥ ☦
Аминь.
```

`echo -n A` → `B`.

### 3. Тройка семёр — `examples/multiply.hbf`

`3 × 7 = 21`, выведенное одним знаком `☥` — без единого цикла:

```text
Господи, помилуй! 3 × 7 = 21 — возвестим числом одним знаком.
♥ ♥ ♥           — в первой ячейке 3
♠               — переходим во вторую
♥ ♥ ♥ ♥ ♥ ♥ ♥   — в ней 7
♣               — назад к тройке
✖               — 3 × 7 = 21
☥               — возвестить «21»
Аминь.
```

## Запуск

Основной интерпретатор — `hbf.cpp` (C++17, без зависимостей):

```bash
g++ -std=c++17 -O2 -o hbf hbf.cpp

# Hello World
./hbf examples/hello.hbf

# прочитать букву и вывести следующую
echo -n A | ./hbf examples/next_char.hbf

# 3 × 7 = 21
./hbf examples/multiply.hbf

# программа строкой
./hbf -e '♥♥♥♠♥♥♥♥♥♥♥♣✖☥'   # 3 × 7 = 21
```

Эталонная реализация на Python сохранена для сравнения — `hbf.py`
(те же ключи: файл, `-e`, `--stdin`):

```bash
python3 hbf.py examples/hello.hbf
```

Символы в командной строке удобно вставлять из таблиц выше.

## Тесты

```bash
python3 test.py
```

Скрипт собирает `hbf.cpp` и прогоняет один набор программ через обе
реализации (C++ и Python): файлные примеры, все 16 команд, ошибки
освящения, переполнение и стоп `Ω`. Коды выхода и вывод обязаны совпасть.
На каждый push те же тесты гоняет GitHub Actions
(см. `.github/workflows/ci.yml`).

## In a nutshell (English)

**Holy Brainfuck** is an esolang inspired by Brainfuck. Instead of
`> < + - . , [ ]`, all **16** instructions are Orthodox crosses and sacred
symbols: `♠ ♣ ♥ ♦ ☦ ✞ ✟ ✠ ✝ ☚ ☛ ✖ ☨ ☧ ☥ Ω`. Everything else is
ignored, so any program can be wrapped in prayers in any language.

- `hbf.cpp` — primary interpreter (C++17, no dependencies); `hbf.py` — Python reference
- Build: `g++ -std=c++17 -O2 -o hbf hbf.cpp`
- Run: `./hbf examples/hello.hbf` · `echo -n A | ./hbf examples/next_char.hbf`
- Tests: `python3 test.py`
